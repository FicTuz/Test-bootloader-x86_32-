Russian|Русский: это небольшой 32-х битный загрузчик который:

грузит 64 сектора

грузит ядро по адресу 0x7E00

грузит ядро по сектору 2 (если начинать считать от 1) или 1 (если начинать считать от 0) то есть следующий сектор после загрузчика

его может использовать кто угодно как захочет:)!

English|Английский: this is a small 32-bit bootloader that:

loads 64 sectors

loads the kernel at address 0x7E00

it loads the kernel in sector 2 (if you start counting from 1) or 1 (if you start counting from 0), that is, the next sector after the loader

anyone can use it any way they want :)!
